# Biblioteca de imágenes

Carpeta para recursos visuales del portfolio: retratos de actores, portadas de proyectos, fotografías y otros materiales gráficos.

Organización recomendada:
- `actores/` — retratos y fotografías de reparto.
- `portadas/` — portadas y cabeceras de proyectos.
- `proyectos/` — imágenes adicionales de cada proyecto.

Mantener los nombres de archivo claros y evitar duplicados. Preferir WebP para imágenes web y conservar los originales fuera del repositorio cuando no sean necesarios para la publicación.
